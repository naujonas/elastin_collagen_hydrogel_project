# Biomimetic elastin-collagen hybrid hydrogels crosslinked by energetic electrons: towards a tunable in vitro extracellular matrix model of the lung

DOI: https://www.doi.org/10.1016/j.matdes.2025.114617

## Contents
- Raw data
- Processed data
- Analysis scripts

Code and Data are available for deformation experiments (rheology), pore analysis, cell viability and proliferation, and cell invasion.

Individual .txt files and microscope images are available upon request from the corresponding author of the manuscript or from Jonas Naumann via jonas.naumann(at)uni-leipzig.de
or the GitHub massaging function.

## Experimental Model
Elastin-collagen hydrogels crosslinked by energetic electrons
